# Project-PAA

Projek PAA ini adalah Smart Courier. Smart Courier adalah sebuah program simulasi pengiriman paket yang cerdas dan interaktif.
Dalam program ini, kurir bertugas untuk mengantarkan paket dari satu titik (source) ke titik lainnya (destination).

Smart Courier memiliki fitur peta yang dapat dimuat dari file gambar dan bersifat dinamis — baik posisi kurir maupun titik pengiriman akan diacak secara otomatis. Navigasi kurir dilakukan berdasarkan arah hadapnya. Artinya, jika kurir menghadap ke kanan, maka hanya bisa berjalan ke arah kanan. Kurir tidak dapat "drifting" ke arah yang berbeda dari arah hadap, serta tidak dapat menembus keluar dari jalur map yang telah ada atau map yang sedang digunakan.

Kurir direpresentasikan dengan gambar yang menunjukkan arah hadap (bukan kotak atau bola polos), seperti mobil atau segitiga, sehingga arah gerak dapat terlihat secara visual. Desain ini dibuat untuk menghindari terjadinya gerakan tak logis seperti drifting atau teleportasi.
