📦 Simulasi Kurir Cerdas dengan Algoritma A*
Proyek ini merupakan simulasi pergerakan kurir cerdas yang mampu menentukan rute tercepat dan efisien dari titik awal menuju lokasi pengambilan (pickup) hingga ke lokasi tujuan. Simulasi ini berjalan di browser menggunakan HTML5 Canvas dan JavaScript, dan mengimplementasikan algoritma pencarian jalur A* (A-Star) untuk menentukan rute terbaik berdasarkan peta grid.

🚀 Fitur Utama
✅ Pemilihan titik awal (start), pickup, dan tujuan (goal) secara interaktif di grid.
✅ Simulasi pergerakan kurir secara animasi dari titik awal ke tujuan.
✅ Penentuan rute tercepat menggunakan algoritma A*.
✅ Tampilan visual rute dan node yang dilalui.
✅ Opsi pemilihan peta atau grid yang bisa disesuaikan.

🛠️ Teknologi yang Digunakan
HTML5: Untuk struktur halaman dan canvas.
CSS3: Untuk tata letak dan gaya visual.
JavaScript (Vanilla): Untuk logika simulasi, algoritma A*, dan interaksi pengguna.
Canvas API: Untuk menggambar peta, node, dan animasi kurir.
